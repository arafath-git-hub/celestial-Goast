
# Abandoned but Not Forgotten

### NASA's Forgotten Equipment on the Moon and Mars

**Abandoned but Not Forgotten** is a futuristic, interactive storytelling website exploring the abandoned equipment, forgotten machines, and historical artifacts left behind by NASA's space missions on the Moon and Mars.

Some machines stopped working. Some missions ended. But their stories remain.

---

##  About The Project

Humanity has explored the Moon and Mars for decades.

During these missions, astronauts and robotic explorers left behind scientific instruments, lunar modules, rovers, and other equipment.

This project explores those forgotten objects and tells the stories behind them.

##  Installation

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

---

##  GitHub Pages Deployment

1. Upload all project files to your GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Under Build and Deployment, select Deploy from a branch.
5. Select the `main` branch.
6. Select `/ (root)` as the folder.
7. Click Save.

Your website will be published at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```
